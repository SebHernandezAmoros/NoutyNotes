# Trabajo en NoutyNotes

- No ejecutar comandos de Git ni crear commits, remotos o publicaciones. Al terminar un cambio, entregar únicamente un mensaje de commit sugerido al usuario.
- La documentación de trabajo está en `Docs/`, no en `wiki/`. Leer `Docs/progress.md` y la fase actual de `Docs/roadmap.md`; actualizar estado y bitácora con evidencia real.
- Consultar el plan maestro local antes de una fase importante. Las instrucciones más recientes del usuario prevalecen sobre ese documento.
- Trabajar una fase por entrega. El dominio no depende de React, Expo ni filesystem. No implementar funcionalidades de fases posteriores.
- Usar Codebase Memory como ayuda de consulta, contrastando cobertura y archivos locales. `Docs/` se consulta directamente.
- Verificar los comandos relevantes y distinguir configuración preparada de ejecución comprobada. No afirmar ejecución Android por un bundle o prebuild.
