# Aplicación y casos de uso

Ubicación reservada para operaciones como crear tarjetas, moverlas, conectar y guardar workspaces. Se organizará por funcionalidades a medida que existan casos reales.

Depende del dominio. Declara los puertos que necesitan sus casos de uso y recibe adaptadores desde la raíz de composición. No importa implementaciones de storage ni frameworks de UI.
